Privacy policy

forkmob tools ("the app") is a desktop tool run by the owner of the Fork Mob channels on their own computer. It is used only with the owner's own YouTube and Instagram accounts.

What the app accesses

  • Permission to upload videos to the owner's YouTube channel.
  • Read-only access to that channel's videos, comments and statistics (views, likes, comments, shares, watch time, subscribers gained), to report them to the owner.

How the data is used and stored

  • All data stays on the owner's computer. Nothing is sent to any server run by the app, and nothing is sold or shared with anyone.
  • The sign-in token from Google is stored only on that computer and is used only to make the requests listed above.
  • The app reads public comments on the owner's own videos only to count viewer votes; it does not build profiles of viewers or other users.

Google API Services

The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. It uses YouTube API Services; see the YouTube Terms of Service and the Google Privacy Policy.

Removing access

Access can be removed at any time at myaccount.google.com/permissions. Deleting the app's data files removes everything it stored.

Contact

Questions: use the contact email on the YouTube channel's About page.
